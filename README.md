# scanzone

Scan URLs and zone query parts with stable normalization.

**Site:** https://theworker02.github.io/scanzone/

## Install / run

```bash
git clone https://github.com/theworker02/scanzone.git
cd scanzone
node src/cli.js
node --test
```
